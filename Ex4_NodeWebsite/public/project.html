🏗 Architecture

This project demonstrates the complete lifecycle of a cloud-native application, from local development to automated deployment on Kubernetes. It integrates Infrastructure as Code, containerization, CI/CD, monitoring, security, HTTPS, load balancing, and cloud deployment using production-oriented practices.

Current Platform

⭐ Implemented Features

Production Ready

The following capabilities are currently implemented and running in the live AWS-hosted Kubernetes environment.

📦

Application and Containers

  • Node.js and Express REST API
  • Docker containerization
  • Docker Hub image registry
  • Non-root container execution
  • Redis-backed shared application state
  • Unique visitor and page-view analytics
☸

Kubernetes Platform

  • Two-node K3s Kubernetes cluster
  • Dedicated control-plane and worker nodes
  • Three application replicas
  • Kubernetes Deployments and ReplicaSets
  • Rolling updates and self-healing
  • Namespaces, ConfigMaps, and Services
🌐

Networking and Security

  • Traefik Ingress Controller
  • ClusterIP application Services
  • Custom GoDaddy domain and DNS
  • HTTPS with Let's Encrypt
  • Automated certificates with cert-manager
  • AWS security-group configuration
🔄

CI/CD and Automation

  • GitHub Actions CI/CD pipeline
  • Automated Docker image builds
  • Automated Docker Hub publishing
  • Trivy image vulnerability scanning
  • Automated Kubernetes deployment
  • Deployment commit and version metadata
🏗️

Infrastructure as Code

  • AWS EC2 infrastructure
  • Terraform worker-node provisioning
  • Terraform-managed security groups
  • Automated networking rules
  • Elastic IP and stable public access
  • Version-controlled infrastructure configuration
📊

Monitoring and Observability

  • Prometheus metrics collection
  • Grafana monitoring dashboards
  • Node Exporter host metrics
  • kube-state-metrics integration
  • Live cluster-health homepage metrics
  • Interactive Kubernetes resource details

🚀 Future Roadmap

In Progress

The next project phases will focus on application packaging, GitOps, scalability, stronger security, centralized logging, alerting, and disaster recovery.

1

Helm Application Packaging

Next

Convert the existing Kubernetes manifests into a reusable Helm chart with configurable values for replicas, image tags, resources, networking, ingress, and environment-specific settings.

Helm Templates values.yaml
2

GitOps with Argo CD

Planned

Replace direct SSH-based Kubernetes deployments with a GitOps workflow where Argo CD continuously compares the live cluster with the desired state stored in Git.

Argo CD GitOps Auto Sync
3

Autoscaling and Resource Optimization

Planned

Implement Horizontal Pod Autoscaler policies and improve resource requests and limits based on live Prometheus measurements.

HPA Metrics Server Scaling
4

Centralized Logging

Planned

Add Grafana Loki and a log collector such as Promtail to centralize application, ingress, and Kubernetes logs inside Grafana.

Loki Promtail Grafana
5

Alerting and Notifications

Planned

Configure Prometheus Alertmanager to send notifications when nodes become unavailable, Pods fail, memory usage increases, or deployments lose available replicas.

Alertmanager Prometheus Rules Notifications
6

Improved Kubernetes Security

Planned

Add NetworkPolicies, Kubernetes security contexts, external secret management, stricter RBAC policies, and additional supply-chain security controls.

NetworkPolicy RBAC Secrets
7

Advanced Deployment Strategies

Planned

Introduce blue/green or canary deployments to reduce deployment risk and validate new application versions before directing all production traffic to them.

Canary Blue/Green Progressive Delivery
8

Backup and Disaster Recovery

Planned

Introduce automated Kubernetes backups using Velero and define recovery procedures for cluster resources, persistent monitoring data, and application state.

Velero Backup Recovery
9

Multi-Environment Delivery

Planned

Create separate development, staging, and production values and deployment configurations to demonstrate environment promotion through CI/CD and GitOps.

Development Staging Production
